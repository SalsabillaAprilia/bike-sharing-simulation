# Dataset

Unduh **Bike Sharing Dataset** dari halaman resmi UCI:
https://archive.ics.uci.edu/dataset/275/bike%2Bsharing%2Bdataset

Ekstrak ZIP dan salin `hour.csv` ke folder ini sehingga path akhirnya:
`data/raw/hour.csv`

Dataset memiliki lisensi CC BY 4.0. Cantumkan atribusi kepada Hadi Fanaee-T dan UCI Machine Learning Repository.
